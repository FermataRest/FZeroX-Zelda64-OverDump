# FZeroX-Zelda64-OverDump
This is a development cartridge containing a retail build of F-Zero X, however what makes this cartridge special is that it contained an overdump for a very early version of The Legend of Zelda: Ocarina of Time from around the time of Nintendo’s SpaceWorld 1997 tradeshow. The data for Ocarina of Time contains maps, textures and text.
