Here's maps available from this early Zelda build which was partially overwritten by F-Zero X.

While we may not have the entire build, we can at least explore early Hyrule.

Keep in mind that this only split map files that use the final game's map header format.
Really early maps didn't get split properly. 
For example, map95 has the inside of Link's Kokiri home, but there's an early map right after that.
Uses some early header. Those were not split.

These will likely each need a scene file built with collision to load in-game.
The actor lists are also likely incompatible with the final game when injected.
Good luck injecting in the final game!
